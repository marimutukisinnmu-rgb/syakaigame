# 資料保管庫

この `docs` ブランチは、超大規模HTML経済社会ゲームに関する調査資料・設計メモ・参考情報を保管するためのブランチです。

## 保管資料

- [日本法令データ全件確認・経済社会ゲーム向け制度設計メモ](japan-law-data-review.md)

このレポートには、提供された法令XML ZIPの機械的な検査結果、データ構造の整理、関連する法令分野、ゲーム内制度の設計案、法令データの出典・利用条件に関する注意を記録しています。

## 注意

資料は調査・開発の参考用です。法令の最新性や、個別事案への法律の適用を保証するものではありません。正式な条文と最新の施行状況は、必ず公式情報で確認してください。

リポジトリ本体の開発内容は `main` ブランチを参照してください。
